液态玻璃卡片：一次 CSS 参数调优记录

多层 inset 阴影、内部模糊暗边、对角线高光，加上父容器的 contrast(3)——一层层堆出来的玻璃感。

想要的质感

目标不是「半透明毛玻璃」，而是边缘有折射、中心有厚度的那种玻璃。纯 backdrop-filter: blur() 只会得到一层雾，缺少高光，看起来像塑料片。

四层结构

一个卡片由四个视觉层叠起来：

  1. 底色：极高的透明度，只给一点白；
  2. 内阴影：模拟边缘折光，这是最关键的一层；
  3. 暗边：::before 加一层模糊的内描边，制造厚度；
  4. 高光：::after 用 45° 的线性渐变，只在两个对角留下白色。
.glass {
  background: rgba(255, 255, 255, 0.04);
  backdrop-filter: blur(2px) brightness(1.1);
  border: 1px double rgba(255, 255, 255, 0.1);
  border-radius: 24px;
  box-shadow:
    inset 2px -2px 1px -1px rgba(255, 255, 255, 0.5),
    inset -2px 2px 1px -1px rgba(255, 255, 255, 0.5),
    inset 6px -6px 1px -6px rgba(255, 255, 255, 0.3),
    inset -6px 6px 1px -6px rgba(255, 255, 255, 0.3),
    inset 0 0 2px rgba(0, 0, 0, 0.5),
    0 4px 8px rgba(0, 0, 0, 0.3);
}

注意每层 inset 的偏移方向是成对的：2px -2px 和 -2px 2px，这样四个角都有亮边，但亮度不一，玻璃才有方向感。

为什么父容器要 contrast(3)

内阴影本身对比度很低，在深色背景上几乎看不见。给容器加 filter: contrast(3) 会把这一层层的细微亮度差放大，边缘立刻「立」起来。

副作用也很明显：容器内的所有文字对比度一起被拉高，浅色字体容易过曝。所以文字不能放在被 contrast 影响的容器里，或者要单独反抵消。

得到的教训

  • 玻璃效果高度依赖背景：背景越丰富，效果越好，纯色背景上完全不成立；
  • blur(2px) 比 blur(20px) 更像玻璃，大模糊是磨砂，不是玻璃；
  • 这套写法在移动端要降级，Safari 叠加多层 inset 阴影会掉帧。
