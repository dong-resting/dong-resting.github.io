用 Hugo 重做博客：从手写页面换到模板

之前首页是一张张手调的 CSS，加点文章就得改结构。换成 Hugo + Stack 之后，写 Markdown 就够了。

为什么换

之前那版首页是纯手写的：背景视频、液态玻璃卡片、翻页按钮全是自己调的 CSS。好看是好看，但每加一篇文章都要动 JS 里的数组，分类和归档更是没有。

真正的问题不是麻烦，是结构没有承载信息。文章的日期、分类、标签都只存在于一个 JS 对象里，搜索不到、归档不了，也生成不了 RSS。

换成什么

Hugo + Stack 主题：

  • 每篇文章是一个 Markdown 文件，带 front matter；
  • 分类、标签、归档、搜索、RSS、面包屑都由模板生成；
  • 亮暗主题、目录、代码高亮、相关文章都是现成的。

目录结构

blog-hugo/
├── config/_default/
│   ├── hugo.toml        # 站点、分页、Markdown 渲染
│   ├── params.toml      # 侧栏、组件、文章选项
│   ├── menu.toml        # 社交图标
│   └── languages.toml   # 中文站点信息
├── content/
│   ├── post/<slug>/index.md
│   └── page/{about,archives,links,search}/index.md
├── static/img/          # 头像等静态资源
└── themes/stack/        # 主题

文章用 page bundle 形式（post/slug/index.md），封面图放在同一个目录里，front matter 里写 image: cover.jpg 就能用，Hugo 还会自动裁缩略图。

中文的几个设置

defaultContentLanguage = "zh"
hasCJKLanguage         = true

hasCJKLanguage 必须开，否则 .Summary 和阅读时长的字数统计会把一整段中文当成一个词。

配色

主题默认是深蓝灰强调色。我在 assets/scss/custom.scss 里覆盖了几个 CSS 变量，把强调色换成琥珀金，标题换成了衬线字体——具体代码见那篇调色记录。

代价

  • 构建需要 Hugo（extended 版本，主题用了 SCSS）；
  • 模板改起来不如手写 HTML 直观，得先读一遍 partial。

但换来的是：以后只写 Markdown。
